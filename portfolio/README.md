# Professional Resume Website

A modern, responsive resume website built with HTML, CSS, and JavaScript. This template features a clean design, smooth animations, and is fully customizable to showcase your professional experience and skills.

## Features

- Responsive design that works on all devices
- Smooth scrolling navigation
- Modern animations and transitions
- Clean and professional layout
- Easy to customize sections
- Social media integration
- Skills showcase with animations
- Interactive experience timeline

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content in `index.html` with your personal information
4. Modify the styling in `styles.css` to match your preferred color scheme
5. Add your own profile picture by replacing the placeholder image URL
6. Update the social media links in the contact section
7. Add your own experience items and skills

## Customization

### Personal Information
Edit the following sections in `index.html`:
- Your name and professional title in the hero section
- About me section with your professional summary
- Work experience items with your job history
- Skills section with your technical and soft skills
- Contact information and social media links

### Styling
You can customize the appearance by modifying `styles.css`:
- Change colors by updating the color values
- Modify the layout by adjusting the CSS properties
- Update fonts by changing the font-family properties
- Adjust spacing and sizing as needed

### Animations
The JavaScript animations can be modified in `script.js`:
- Adjust animation timing and effects
- Add new interactive features
- Modify the scroll behavior

## Browser Support

This website is compatible with all modern browsers:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
